
# Python Expense Tracker

A beginner-friendly expense tracker built using Python.

## About the Project

This project helps users record and manage their daily expenses using a simple Python program.

## Features

- Record daily expenses
- Enter expense details
- Track spending
- Simple and beginner-friendly program

## Technologies Used

- Python

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

   python expense_tracker.py

- Practising Python programming
- Understanding user input
- Improving problem-solving skills
